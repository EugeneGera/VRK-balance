# Производственный баланс

React + Flask + PostgreSQL: производство, остатки, ограничения, распределение заявок и аналитика.

Добавлен отдельный аналитический API и read-only MCP-сервер с пятью инструментами. UI и MCP используют общий расчётный слой; агент формирует текст отчёта в своём MCP-клиенте.

Подробные контракты, права, контрольные примеры и инструкции: [docs/mcp.md](docs/mcp.md).

На панели баланса нажмите **«Подготовить отчёт»**. Откроются сводка, сравнение периодов и детализация по текущим фильтрам. Под отчётом можно задать вопрос по показателям.

Локальный запуск на Mac — двойной щелчок по `Запустить.command` или команда:

```sh
make start
```

Скрипт запустит Docker и Ollama и откроет панель в браузере. Для остановки используйте `Остановить.command` или `make stop`. Команда `make start-full` запускает полную модель, указанную в настройках.

[Запуск и локальные модели](docs/assistant.md) · [Контракты API и MCP](docs/mcp.md)

Тесты бэкенда:

```sh
PYTHONPATH=backend python3 -m unittest discover -s backend/tests -v
```

Для контрольных сравнений UI/API/MCP используются `experiments/control_cases.json` и отдельная экспериментальная БД. Рабочую БД скрипт проверки не изменяет.
