# Отчёты на панели баланса

Кнопка **«Подготовить отчёт»** открывает боковую панель с текущими фильтрами. Выберите «Сводка», «Сравнение» или «По базисам» и запустите расчёт. Календарь «С чем сравнить» появляется в режиме «Сравнение» и предлагает предыдущий период по умолчанию. Каждый запуск заменяет текущий результат. Уточнение отправляется с контекстом этого отчёта. Источники отчёта содержат фильтры, ссылки на экранные таблицы и идентификаторы запросов.

Старый адрес `/balance_comission/analytics` открывает эту панель внутри баланса.

## Запуск на Mac

- Двойной щелчок по `Запустить.command` в корне проекта.
- Та же операция из терминала командой `make start`.

Скрипт проверяет Docker Desktop и запускает Ollama из `.runtime/ollama`, PATH или приложения macOS. Затем он поднимает PostgreSQL, API, MCP, сервис отчётов и фронтенд. После пробного ответа модели откроется `http://localhost:3000/balance_comission`.

Используйте `make stop` или `Остановить.command` для остановки контейнеров с сохранением данных. `python3 scripts/start.py --no-browser` запускает те же сервисы для автоматической проверки.

## Модели и данные

По умолчанию скрипт предпочитает установленную модель из `.env.analytics`. Если её нет, он запускает компактную Qwen3 0.6B (523 МБ). Для загрузки и запуска полной Qwen3.5 4B используйте `make start-full`. Интернет понадобится для отсутствующих весов и образов. Повторный запуск использует локальный кэш.

Бэкенд вычисляет объёмы и изменения. Модель выбирает факты для пояснения, а текст и таблицы строятся по данным MCP. Компактный режим работает с выбранными фильтрами и поддерживает уточнения по показателям и базисам. Сравнение и произвольный выбор периода доступны через поля отчёта. 

Скрипт использует существующий контейнер PostgreSQL и загружает `BK.sql` только в пустую базу. Ключи остаются в `.env.analytics`, веса и журналы — в `.runtime`. При самостоятельном запуске Ollama настройка `OLLAMA_NO_CLOUD=1` сохраняет локальный режим.

Для проверки выберите декабрь 2025 года и категорию «Бензин АИ-92». Сравнение с ноябрём показывает 657 → 734 тыс. т и изменение +77 тыс. т. Затем можно спросить «Покажи распределение по базисам».
