# Проверка реализации MCP

Дата: 17 ноября 2026 года.

Проверки выполнялись на отдельной PostgreSQL 15. Рабочая БД проекта и `BK.sql` не изменялись. В тестовую БД восстановлен дамп с SHA-256 `b306bbebc50c0c3f32eb5939764e60cade9d0ed91d2e00baec3980b09e92acd5`, затем загружены `experiments/edge_cases.sql`.

| Проверка | Результат |
|---|---|
| Бэкенд, Python 3.8 в контейнере | 26 тестов, успешно |
| MCP, Python 3.12 в контейнере | 6 тестов, успешно |
| MCP, локальный Python 3.13 | 6 тестов, успешно |
| Контроли UI/API/настоящий stdio MCP | 13 из 13 |
| Те же контроли через HTTP MCP в Docker | 13 из 13 |
| HTTP без ключа | 401 |
| HTTP с ограниченным ключом | Только разрешённые продукт и базис; запрос другого продукта отклонён |
| Панель в Chrome | Начальная дата — декабрь 2025, отображаются диаграммы |
| Журнал в Chrome | Открывается с явными фильтрами ноября 2025 |
| Ошибки JavaScript и запросы старого access control | Не обнаружены |

Для АИ-92 в ноябре контроль подтверждает ресурс 722, распределение 657, биржу 216 тыс. т; в декабре — распределение 734 тыс. т. Разница +77 вычислена бэкендом. Снимки источников совпадают между экранным API, аналитическим API и MCP.

Отдельно проверены разные единицы, нулевые и отсутствующие показатели, пустой период, ошибочные фильтры и даты, дубли заявок, независимость последовательных запросов, пагинация и изменение снимка.

Это техническая проверка корректности. Полное время подготовки отчёта человеком или агентом не измерялось; шаблон такого эксперимента находится в `experiments/measurements.csv`.

Команды повторения и контракты: [mcp.md](mcp.md).

## Дополнение: фронтенд и локальный агент

- Бэкенд: 31 тест, включая шлюз помощника и передачу прав вызывающего пользователя.
- Сервис агента: 15 тестов; MCP: 6 тестов. Вызов модели в модульных тестах заменён управляемым локальным HTTP-ответом/тестовым адаптером.
- Production-сборка фронтенда проходит. Новых ошибок TypeScript нет; общий `tsc` сохраняет существующие ошибки загрузки файлов и типизации Highcharts, воспроизведённые на исходном фронтенде.
- Chrome: переход с панели, перенос фильтров, три задания, сравнение 657 → 734 (+77), четыре базиса, ссылки на источники, очистка диалога при смене фильтров. Ошибок JavaScript нет.
- При блокировке всех внешних запросов браузера сценарий готовых отчётов работает. Узкий экран 390 px не создаёт горизонтального переполнения страницы.
- Полный серверный путь через агент/MCP различает ноль, неизвестное и пустую выборку; ограниченный ключ возвращает только разрешённые данные.
- Нативная Ollama 0.40.16 запускается на Apple M1 Pro, обнаруживает Metal GPU. Облачные функции отключены. Контейнер агента достигает Ollama на localhost Mac через `host.docker.internal` без открытия порта в локальную сеть.
- Реальные ответы Qwen и их скорость требуют завершённой первоначальной загрузки весов; эту проверку нельзя подменять результатами тестового адаптера.
